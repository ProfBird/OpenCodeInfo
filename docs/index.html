Stealth-model notes — what Big Pickle and Ox Alpha are

Both are stealth (anonymous-preview) models served free for a limited time while the providers collect feedback. OpenCode and OpenRouter use the same upstream previews under different IDs and data-handling terms. Neither provider has published an official de-anonymization.

Big Pickle — big-pickle / opencode/big-pickle

What it is: OpenCode Zen's free stealth coding model served at https://opencode.ai/zen/v1/chat/completions via @ai-sdk/openai-compatible. Specs consistently reported as 200K context / 32K max output, text-in + reasoning, function-calling, $0 in/out/cached during the preview (see Zen endpoints table and pi.dev model record). OpenCode's Zen page describes it as "a stealth model that's free on OpenCode for a limited time. The team is using this time to collect feedback and improve the model" — and its Privacy section notes that for Big Pickle, collected data may be used to improve the model during the free period (so not zero-retention).

Who built it? OpenCode has not named a developer. Community consensus on X, Discord and GitHub is that Big Pickle is Zhipu AI's GLM-4.6 (same 200K window, similar behavior, tokenizer/architecture overlap), but this is unconfirmed — OpenCode leaves the identity undisclosed. The question was asked directly in anomalyco/opencode#4276 “Is zen/big-pickle glm 4.6?”; community write-ups (e.g. Grokipedia Big Pickle, Aftab's big-pickle protocol note) repeat the GLM-4.6 attribution as consensus, not official confirmation. Do not treat the attribution as authoritative.

History / chatter: Discussed heavily on OpenCode Discord and on X via @opencode community threads; error logs during spring 2026 (issues #28141, #28138) also exposed upstream routing details.

Ox Alpha Free — x-preview-f-free (Zen) / stealth/ox-alpha (OpenRouter)

What it is: Anonymous reasoning model for coding, sustained agentic work and production workloads released Aug 20, 2026 simultaneously on OpenRouter as stealth/ox-alpha and on OpenCode Zen as x-preview-f-free (Ox Alpha Free). OpenRouter describes it as "a reasoning model designed for coding, sustained agentic work, and production workloads … It is suited for long-horizon software engineering, complex reasoning, and workflows that combine text with visual context" — 1,048,576-token context, up to 131,072 completion tokens, text+image+video → text, tool-calling + structured output (JSON), $0/M tokens in preview.

Announcements (X): OpenRouter on X, Aug 20 — “New stealth model: Ox Alpha … frontier model built for efficient coding, sustained agentic work, and real-world production use”; OpenCode on X, Aug 20 — “Ox Alpha (stealth model) is free for the next week — 1M Context, Multi-modal, Zero Data Retention. … 100T tokens/day capacity”; OpenCode on X, Aug 21 — near-unlimited free on OpenCode Go for 6 more days, not counted against Go quotas. Early traffic dashboards showed Hermes Agent / Claude Code among top consumers.

Privacy — the two routes differ: OpenRouter's model page states "Prompts and completions for this model are retained by the provider and are not used for training; all other use is governed by the Stealth Model Terms". OpenCode's Zen docs state the opposite for its route: "Ox Alpha Free is a stealth model … Its provider follows a zero-retention policy and does not use your data for model training" (also listed explicitly under Pricing as Free and under the free-models blurb). Treat the Zen x-preview-f-free route as ZDR-per-OpenCode and the OpenRouter stealth/ox-alpha route as retained-but-not-trained per OpenRouter — do not send secrets to either without your own review.

Who built it? OpenRouter lists the provider as Stealth (anonymous) — "developed and operated by a third-party provider who has chosen to remain anonymous … OpenRouter routes requests to it and is not its developer, owner, or provider." No lab has claimed it. Independent forensics on Aug 22 (researcher @chetaslua, summarized by explainx.ai and follow-up forensics post) found serving-layer signals supporting a leading-but-unconfirmed theory that the upstream is Zhipu AI / Z.AI infrastructure (Java stack trace com.wd.paas.api…, error code 1214, 30/30 tokenizer overlap with GLM-5 family, video-token behavior matching GLM-5V). TechCrunch's Aug 23 coverage also notes the frenzy is speculation — no official reveal. Treat any lab attribution as theory until the provider de-anonymizes.

Also called 0x Alpha: the official listing is Ox (letter O); “0x Alpha” / “0xAlpha” are common mistypings because Ox looks like a hex prefix.
