SWE-bench Pro: Scale AI's contamination-resistant coding benchmark (1,865 tasks, standardized harness), mirrored from BenchLM. OpenAI's July 2026 audit found ~30% of its public tasks broken, so treat scores as directional.

Terminal-Bench: Laude Institute's agentic terminal & CLI coding benchmark, mirrored from BenchLM. Shows Terminal-Bench 2.1 where published, else 2.0. — = not published.

DeepSWE: Datacurve's contamination-free long-horizon repo benchmark (113 tasks, 91 repos), pass@1 %, mirrored from BenchLM. Only models with a published score are shown (— = not published).

Free tiers run no benchmark suites of their own and show the scores of the non-free model they serve (e.g. Ox Alpha = GLM-5.3-Flash per Z.ai). Scores marked ? (Big Pickle) are its presumed GLM-4.6 identity's published scores — uncertain because the identity is not officially confirmed.

Stealth-model notes

Both are stealth (anonymous-preview) models, free for a limited time. Neither provider has named a developer, and neither has an official AA Coding Index score.

Big Pickle — big-pickle (OpenCode Zen)

Free stealth coding model, 200K context / 32K output, $0 in/out. Zen docs call it “a stealth model … free for a limited time”; data may be used to improve the model during the free period (not zero-retention).

Identity: undisclosed, but almost certainly Zhipu AI's GLM-4.6 (~357B-param MoE): an OpenCode maintainer answered “Yes it is” when asked exactly that in opencode#4276 (Nov 2025), and community consensus (Reddit/X/Grokipedia) agrees. The profile fits: 200K context / 32K output, text-only, knowledge cutoff 2025-01, released Oct 17, 2025. Two caveats: (a) it is still not officially confirmed, so params are shown as 357B? — a trailing ? marks inferred/uncertain values on this page; (b) an Aug 2026 community run (SWE Atlas) reported leaked provider errors suggesting the serving infrastructure may have changed (DeepSeek signatures) — stealth aliases can swap the underlying model without notice. It is not GLM-5.3-Flash: that model has a 1M context, text+image+video input, and an Aug 2026 release — and the stealth model identified with GLM-5.3-Flash is Ox Alpha, not Big Pickle.

Benchmarks (community, unofficial): SWE Atlas Codebase QnA 50.8% (63/124) — source; ORPT-Bench 0.615 composite / 67% success — source.

Benchmarks via GLM-4.6 (shown with ? — inherited from the unconfirmed identity): Terminal-Bench v2.1 49.4? (Artificial Analysis's own independent run, from its GLM-4.6 model page, which displays it rounded as 49%); SWE-bench Pro 9.67? ±2.15 (Scale AI public leaderboard, Jan 2026). The SWE-bench Pro score is surprisingly low — it sits below same-era open peers (Qwen3-Coder-480B 38.70, Kimi K2 27.67, DeepSeek V3.2 15.56) despite GLM-4.6's CC-Bench parity with Claude Sonnet 4 — and harness choice dominates that board (top entries are marked *Run with mini-swe-agent harness; the GLM-4.6 run's harness is undisclosed), so the low value may reflect an unfavorable config as much as model skill. Sub-10 scores are nonetheless common on the board (Llama 4 Maverick 5.24, Codestral 1.51) and 9.67 is faithfully transcribed from it. GLM-4.6 has no published AA Coding Index (Artificial Analysis deprecated the model and publishes no coding index for it) or DeepSWE — those cells stay —. Other GLM-4.6 numbers exist but for different benchmarks (SWE-bench Verified 55.40 with mini-SWE-agent on swebench.com; vendor-run CC-Bench 48.6% win-rate vs Claude Sonnet 4) and are not comparable to this page's columns.

Ox Alpha Free — x-preview-f-free (Zen) / stealth/ox-alpha (OpenRouter) — likely GLM-5.3-Flash

Anonymous reasoning model released Aug 20, 2026. 1,048,576 context / 131,072 output, text+image+video → text, tool-calling, $0 preview. “Ox” (letter O); “0x Alpha” is a common typo. OpenRouter page, OpenCode X Aug 20.

Privacy differs by route: OpenRouter retains prompts (not for training); Zen claims zero-retention. Check before sending secrets.

Identity — GLM-5.3-Flash (high likelihood): No lab officially claimed Ox Alpha as of Aug 22, but kie.ai (Daniel Okonkwo, Aug 22, 2026) fingerprinting is the strongest signal: modelprint tokenizer probes matched GLM family 4/4 (all other labs ≤2/4), and a reasoning_effort:"none" request returned error [1210] — the same code Z.ai’s GLM-5.3 API returns. Public GLM-5.3 is text-only, so the hypothesis was an unreleased multimodal GLM-5.3 variant. On Aug 26 Z.ai announced GLM-5.3-Flash — 320B total / 18B active, hybrid sparse+linear attention, native multimodal (text/image/video/files), 1M context / 128K output, MIT, $0.15/$0.50 — which matches Ox Alpha’s 1M, video input, and price, making GLM-5.3-Flash the leading identity with high confidence (still not officially confirmed as Ox Alpha). See also Z.ai docs and earlier forensics explainx.ai.

Benchmarks (community, unofficial): DeepSWE 58.4% (66/113) — source; LiveCodeBench v6 pass@1 28.0% — source; 10-task community eval 80% vs Fable 5 65% / GLM-5.3 62% — source; kie.ai table shows same 80% vs 65%/62%/52% — treat as conflicting, unreplicated (kie.ai).
