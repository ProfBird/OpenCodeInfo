Stealth-model notes

Both are stealth (anonymous-preview) models, free for a limited time. Neither provider has named a developer, and neither has an official AA Coding Index score.

Big Pickle — big-pickle (OpenCode Zen)

Free stealth coding model, 200K context / 32K output, $0 in/out. Zen docs call it “a stealth model … free for a limited time”; data may be used to improve the model during the free period (not zero-retention).

Identity: undisclosed. Community consensus on X/Discord/GitHub points to Zhipu AI's GLM-4.6, unconfirmed (opencode#4276).

Benchmarks (community, unofficial): SWE Atlas Codebase QnA 50.8% (63/124) — source; ORPT-Bench 0.615 composite / 67% success — source.

Ox Alpha Free — x-preview-f-free (Zen) / stealth/ox-alpha (OpenRouter) — likely GLM-5.3-Flash

Anonymous reasoning model released Aug 20, 2026. 1,048,576 context / 131,072 output, text+image+video → text, tool-calling, $0 preview. “Ox” (letter O); “0x Alpha” is a common typo. OpenRouter page, OpenCode X Aug 20.

Privacy differs by route: OpenRouter retains prompts (not for training); Zen claims zero-retention. Check before sending secrets.

Identity — GLM-5.3-Flash (high likelihood): No lab officially claimed Ox Alpha as of Aug 22, but kie.ai (Daniel Okonkwo, Aug 22, 2026) fingerprinting is the strongest signal: modelprint tokenizer probes matched GLM family 4/4 (all other labs ≤2/4), and a reasoning_effort:"none" request returned error [1210] — the same code Z.ai’s GLM-5.3 API returns. Public GLM-5.3 is text-only, so the hypothesis was an unreleased multimodal GLM-5.3 variant. On Aug 26 Z.ai announced GLM-5.3-Flash — 320B total / 18B active, hybrid sparse+linear attention, native multimodal (text/image/video/files), 1M context / 128K output, MIT, $0.15/$0.50 — which matches Ox Alpha’s 1M, video input, and price, making GLM-5.3-Flash the leading identity with high confidence (still not officially confirmed as Ox Alpha). See also Z.ai docs and earlier forensics explainx.ai.

Benchmarks (community, unofficial): DeepSWE 58.4% (66/113) — source; LiveCodeBench v6 pass@1 28.0% — source; 10-task community eval 80% vs Fable 5 65% / GLM-5.3 62% — source; kie.ai table shows same 80% vs 65%/62%/52% — treat as conflicting, unreplicated (kie.ai).
