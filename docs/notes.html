Benchmark & data notes

Models with no benchmark score (—) or params (—) sort last on those columns. All AA Coding Index values from BenchLM AA Coding Index (display-only mirror of Artificial Analysis, verified 2026-08-21, e.g. Kimi K3 76.24, GLM-5.3 74.76, Grok 4.5 72.45, Muse Spark 1.2 72.22, DeepSeek V4 Pro 68.83/Flash 69.06 for builds 0813/0731); Vision Exp, LongCat-2.0 etc. have no published AA Coding Index on that page and show —.

Rank: Composite coding benchmark rank across all 7 benchmark suites (AA Coding Index, SWE-bench Pro, Bug Hunt, FrontierCode 2.0, Terminal-Bench 2, Terminal-Bench 4, and DeepSWE) calculated via log-odds latent skill (IRT logistic link) with 2-parameter Mean-Sigma cohort equating and TrueSkill-style conservative Bayesian lower-confidence-bound (LCB) weighting. Suite weights reflect test recency and rigor (Terminal-Bench 4: 1.5×, DeepSWE: 1.5×, SWE-bench Pro: 1.0×, AA Coding Index: 1.0×, Bug Hunt: 1.0×, FrontierCode 2.0: 0.5×, Terminal-Bench 2: 0.5×). Canonical model deduplication prevents Free/Contributor/OpenRouter twins — and dated OpenRouter builds of a model already listed under its bare name — from skewing suite statistics or skipping rank numbers, 2-parameter bridge equating aligns both location and scale across cohorts, and the LCB uncertainty penalty rewards broad multi-suite coverage across the entire table (it scales with how many suites a model has been evaluated on, not with how consistent those results are). Bug Hunt is scored as planted bugs fixed out of 105, converted to a percentage for the latent-skill fit. A rank with a trailing ? (e.g. #89?) rests only on unconfirmed, identity-inferred scores. Unranked models (—) have no published benchmark scores.

SWE-bench Pro: Scale AI's contamination-resistant coding benchmark (1,865 tasks, standardized harness), mirrored from BenchLM. OpenAI's July 2026 audit found ~30% of its public tasks broken, so treat scores as directional.

Bug Hunt: Bug Hunt Bench (Product Compass) hides 105 real bugs in two unrelated production TypeScript repos (a ~28K-line VS Code extension with 45 bugs and a ~60K-line React/Supabase LMS with 60) and grades each model's fixes blind. The number shown is bugs fixed out of 105 (a count, not a percentage) for the model's best published configuration; 23 bugs were fixed by no model. Harness and reasoning effort vary by entry (Claude Code, Codex CLI, Antigravity CLI, …) and materially affect results, so compare within a few bugs rather than exactly. Mirrored from BenchLM where available, otherwise taken directly from the publisher's leaderboard. — = not evaluated.

FrontierCode 2.0: FrontierCode (Cognition) is the first benchmark to score mergeability — would the repository's maintainer actually merge this PR? 132 tasks written by the open-source maintainers of the repos they come from, graded by an ensemble of unit tests, rubrics and verifiers over correctness, test quality, scope discipline, style and adherence to codebase standards; solutions that fail a blocking criterion score 0. The score shown is a weighted aggregate (%), taken from BenchLM's mirror of the official board using each model's best reasoning effort. The cohort is still sparse (~28 models) and per-model runs use different agent harnesses, so it carries half weight in the composite rank. — = not evaluated.

Terminal-Bench 2: Laude Institute's agentic terminal & CLI coding benchmark (89 tasks), mirrored from BenchLM. Shows Terminal-Bench 2.1 where published, else 2.0. — = not published.

Terminal-Bench 4: Laude Institute's newer, harder uncontaminated agentic terminal benchmark (66 tasks), mirrored from BenchLM. Shows Terminal-Bench 4.1 where published, else 4.0 / AA Terminal-Bench 4.0. Not directly comparable to Terminal-Bench 2 due to task redesign and strict anti-leakage isolation. — = not published.

DeepSWE: Datacurve's contamination-free long-horizon repo benchmark (113 tasks, 91 repos), pass@1 %, mirrored from BenchLM. Only models with a published score are shown (— = not published).

Free tiers: Several free models publish their own benchmark evaluations directly (e.g. Ling 3.1 Flash Free, Flint 40B Free, Beam Free), while free variants of paid models inherit scores from their counterpart (e.g. MiniMax M3.1 Flash Free, Step 5 Preview Free, LongCat 2.5 Preview Free, DeepSeek V4.1 Flash 1017 Free, Ox Alpha = GLM-5.3-Flash). Scores marked ? (Big Pickle) are its presumed GLM-4.6 identity's published scores — uncertain because the identity is not officially confirmed.

(N.A.) = Not Available — the model no longer appears in OpenCode's model picker (marked deprecated or removed from the model catalog OpenCode uses), though it may still be listed on OpenCode's pricing pages.

Stealth-model notes

Big Pickle is a free stealth (anonymous-preview) model; Omen Alpha is a paid stealth model exclusive to OpenCode Go. No provider has named a developer for either, and neither has an official AA Coding Index score. A model's name links here — to its note below — from the model table when there is no manufacturer, Hugging Face, or BenchLM page to link to.

Big Pickle — big-pickle (OpenCode Zen)

Free stealth coding model, 200K context / 32K output, $0 in/out. Zen docs call it “a stealth model … free for a limited time”; data may be used to improve the model during the free period (not zero-retention).

Identity: undisclosed, but almost certainly Zhipu AI's GLM-4.6 (~357B-param MoE): an OpenCode maintainer answered “Yes it is” when asked exactly that in opencode#4276 (Nov 2025), and community consensus (Reddit/X/Grokipedia) agrees. The profile fits: 200K context / 32K output, text-only, knowledge cutoff 2025-01, released Oct 17, 2025. Two caveats: (a) it is still not officially confirmed, so params are shown as 357B? — a trailing ? marks inferred/uncertain values on this page; (b) an Aug 2026 community run (SWE Atlas) reported leaked provider errors suggesting the serving infrastructure may have changed (DeepSeek signatures) — stealth aliases can swap the underlying model without notice. It is not GLM-5.3-Flash: that model has a 1M context, text+image+video input, and an Aug 2026 release — and the earlier stealth model identified with GLM-5.3-Flash is Ox Alpha (deprecated Sep 2026), not Big Pickle.

Benchmarks (community, unofficial): SWE Atlas Codebase QnA 50.8% (63/124) — source; ORPT-Bench 0.615 composite / 67% success — source.

Benchmarks via GLM-4.6 (shown with ? — inherited from the unconfirmed identity): Terminal-Bench v2.1 49.4? (Artificial Analysis's own independent run, from its GLM-4.6 model page, which displays it rounded as 49%); SWE-bench Pro 9.67? ±2.15 (Scale AI public leaderboard, Jan 2026). The SWE-bench Pro score is surprisingly low — it sits below same-era open peers (Qwen3-Coder-480B 38.70, Kimi K2 27.67, DeepSeek V3.2 15.56) despite GLM-4.6's CC-Bench parity with Claude Sonnet 4 — and harness choice dominates that board (top entries are marked *Run with mini-swe-agent harness; the GLM-4.6 run's harness is undisclosed), so the low value may reflect an unfavorable config as much as model skill. Sub-10 scores are nonetheless common on the board (Llama 4 Maverick 5.24, Codestral 1.51) and 9.67 is faithfully transcribed from it. GLM-4.6 has no published AA Coding Index (Artificial Analysis deprecated the model and publishes no coding index for it) or DeepSWE — those cells stay —. Other GLM-4.6 numbers exist but for different benchmarks (SWE-bench Verified 55.40 with mini-SWE-agent on swebench.com; vendor-run CC-Bench 48.6% win-rate vs Claude Sonnet 4) and are not comparable to this page's columns.

Omen Alpha — omen-alpha (OpenCode Go)

Paid stealth coding model released Sep 4, 2026, exclusive to OpenCode Go ($10/mo, incl. $100 of Omen Alpha usage). Per models.dev (the catalog OpenCode's model picker consumes): 500,000-token context / 128,000 output, text+image → text, reasoning (low/high effort) + tool-calling, $0.20 in / $0.66 out / $0.04 cached read per 1M tokens. OpenCode claims zero data retention (not used for training). Go docs, BuildFastWithAI review.

Identity — unconfirmed. The leading theory is Zhipu AI / GLM family: OpenCode's own data page files it under a zhipu/omen-alpha path, a community tokenizer analysis (stealthprint, via Developer Memos, Sep 6, 2026) reports a GLM-5 tokenizer with roughly 1M context, and testers note it fails the same coding-test line where Ox Alpha and GLM-5.3-Flash failed. The competing theory is Xiaomi's unreleased MiMo-V3-Flash, from chain-of-thought style resemblance — which OrcaRouter itself calls the weakest class of fingerprint. A fringe guess says Grok. No lab has claimed it. Context is contested: third-party directories list 500K (shown in the table), but first-day testers fed it 850K+ token prompts and got coherent answers. Parameters undisclosed.

Benchmarks (community, unofficial): AI Coding Daily's LLM Coding Leaderboard run (Sep 4, 2026, OpenCode harness) ranked it #16 at 23.14 pts — just below DeepSeek V4 Flash (23.18) and above Qwen3.8 Flash (22.94), at $0.03 and 1:51 per prompt. Community-reported throughput is ~189 tok/s (explainx.ai). No official AA Coding Index, SWE-bench Pro, Terminal-Bench, or DeepSWE — those cells stay —.
